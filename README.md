# نظام إدارة المركز الشبابي الثقافي والتوعوي
### Youth Cultural & Awareness Center Management System

منظومة برمجية متكاملة (Progressive Web App - PWA) لإدارة المراكز الثقافية، الشبابية، والتوعوية، مصممة وفق أحدث معايير الحوكمة المؤسسية وفصل الصلاحيات (Segregation of Duties)، وتعمل بنموذج محلي مستقل بالكامل (**On-Premise Local Server**) دون أي اعتماد على خدمات سحابية خارجية وفق البند 17 من وثيقة المتطلبات.

---

## 🌟 أبرز مميزات النظام

### 1. إعدادات النظام الشاملة (العملة والمود الليلي)
- **التبديل بين الدينار العراقي والدولار الأمريكي**: دعم تسعير الدورات والرسوم والموازنات بالدينار العراقي (`IQD` - `د.ع`) أو الدولار الأمريكي (`$ USD`) مع محول فوري وإمكانية تخصيص سعر الصرف المعتمد.
- **المود الليلي (Dark Mode)**: تبديل سلس بين الوضع النهاري الفاتح والمود الليلي الداكن لحماية العين، مع حفظ التفضيل محلياً وتوافق كامل مع كافة المكونات.
- **سياسات المركز ومعايير الحوكمة**: تخصيص أيام فترة تأهيل الملتحقين، الحد الأدنى لساعات التطوع لإصدار الشهادات، ونافذة تعديل الحضور.

### 2. منظومة شؤون الأفراد والموارد البشرية (HR Management)
- **ملفات موحدة لكافة الكوادر والأفراد**: سجلات رقمية مصنفة للمحاضرين، المتطوعين، المنتسبين والملتحقين الجدد، وأولياء الأمور، والكادر الإداري.
- **الملف الفردي الرقمي (Digital Dossier)**: بطاقة تفصيلية لكل فرد تتضمن السجل التدريبي، ساعات التطوع، إقرارات الوصاية للقاصرين، والأداء.
- **معاينة البوابة كـ هذا المستخدم**: إمكانية انتقال المدير بضغطة زر لمعاينة واجهة أي عضو، مدرب، أو متطوع للتأكد من سير العملية دون ملء الشريط العلوي ببيانات الأفراد.
- **إضافة ملتحقين جدد مباشرة**: للمدير العام ومنسق الأنشطة مع كشف تلقائي للقاصرين وتوثيق بيانات ولي الأمر وموافقته الرسمية.

### 3. تقارير الأداء الشهرية التلقائية والرسوم البيانية (Recharts)
- **توليد تقارير أداء دورية للمدير العام**: إحصائيات تلقائية حول:
  - عدد المنتسبين والملتحقين الجدد شهرياً.
  - الدورات والورش المكتملة ونسب الإنجاز.
  - ساعات التطوع المعتمدة ومستويات الأوسمة (برونزي، فضي، ذهبي).
- **لوحات بيانية تفاعلية (Data Visualization)**: رسوم بيانية توضح مسارات النمو ومعدلات الرضا وساعات التطوع باستخدام مكتبة `Recharts`.
- **جاهزية الطباعة والتصدير**: تصدير التقارير التنفيذية للجهات المانحة ومجالس الإدارة بصيغة قابلة للطباعة والتصدير إلى Excel/CSV.

### 4. إدارة الدورات والمدربين الديناميكية
- **محاضرون متغيرون لكل دورة**: إمكانية إسناد أو تغيير المحاضر المسؤول عن أي دورة تدريبية أو دفعة على الفور، مع إضافة محاضرين جدد على الفور.
- **حضور الجلسات برمز الاستجابة السريعة (QR Code)**: رصد حضور المتدربين ومسح البطاقات الرقمية مع دعم كامل لوضع عدم الاتصال (Offline Queue).
- **قوائم الانتظار التلقائية**: ترقية المسجلين آلياً حال انسحاب أي متدرب.

### 5. الرقابة المالية والحوكمة (Segregation of Duties)
- **سندات القبض الإلكترونية**: تحصيل رسوم الاشتراكات وطباعة الإيصالات الرسمية مع باركود التحقق.
- **اعتماد المصروفات متعدد المستويات**: طلب الصرف يبدأ من المنسق، يعتمده المدير، ويصرفه أمين الصندوق، مع تنبيه فوري حال تجاوز الموازنة.
- **سجل الرقابة والتدقيق غير القابل للتعديل (Immutable Audit Log)**.

## 🛠️ التقنيات المستخدمة (Tech Stack)

| المجال | التقنية |
|---|---|
| **بيئة الواجهة** | React 19 + TypeScript (Strict Mode) |
| **أداة البناء** | Vite 8 + TSX |
| **التنسيق والتصميم** | Tailwind CSS v4 (مع دعم كامل لـ Dark Mode) |
| **الرسوم البيانية والتحليلات** | Recharts v2 |
| **الأيقونات والرموز** | Lucide React |
| **الحركات والتأثيرات** | Motion (Framer Motion) |
| **رموز الاستجابة السريعة** | QRCode Canvas & Scanner |
| **قاعدة البيانات المحلية** | Authoritative Local In-Memory & LocalStorage Engine |
| **إمكانية التثبيت** | Progressive Web App (PWA) |

## 🚀 التشغيل والتثبيت محلياً (Quick Start)

### المتطلبات الأساسية
- Node.js (الإصدار 18 فما فوق)
- npm أو pnpm أو yarn

### خطوات التشغيل

1. **استنساخ المستودع (Clone the repository)**:
   ```bash
   git clone https://github.com/aliahmad1967/SRD_Youth_Cultural_Center.git
   cd SRD_Youth_Cultural_Center
   ```

2. **تثبيت الحزم البرمجية (Install dependencies)**:
   ```bash
   npm install
   ```

3. **تشغيل خادم التطوير المحلي (Start dev server)**:
   ```bash
   npm run dev
   ```
   سيتم تشغيل التطبيق محلياً على الرابط: `http://localhost:3000`

4. **فحص الأنواع البرمجية (Lint & Type-check)**:
   ```bash
   npm run lint
   ```

5. **بناء النسخة الإنتاجية (Build for production)**:
   ```bash
   npm run build
   ```

## 👥 الأدوار ومبدل الحسابات السريع للتجربة

يتضمن النظام حسابات افتراضية مسبقة تغطي كافة الأدوار للتجربة والتقييم:
- **المدير العام**: أحمد المنصور (`u-dir`)
- **المسؤول المالي**: طارق السيد (`u-fin`)
- **منسق الأنشطة**: سارة الخطيب (`u-coord`)
- **محاضر / مدرب**: د. هشام محمود (`u-tr1`)
- **متطوع (ذهبي)**: زيد النجار (`u-vol-1`)
- **ملتحق جديد (قاصر)**: كنان إبراهيم (`u-mem-1`)
- **ولي أمر**: إبراهيم الأحمد (`u-guard-1`)

## 🔒 الخصوصية والعمل دون اتصال (Offline-First)

- التطبيق يعمل محلياً بالكامل (On-Premise) ولا يقوم برفع أي بيانات لأطراف خارجية.
- يتم تخزين الحضور والتقييمات وساعات التطوع عند انقطاع الاتصال، ثم تتم المزامنة تلقائياً عند استعادة الشبكة المحلية.
